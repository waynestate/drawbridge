# DRAWBRIDGE

DRAWBRIDGE is the Citadel auth gateway at auth.apps.wayne.edu: one SAML service provider for all of Citadel that hands apps a trusted identity header. It is part of WELD, the Wayne State application stack, beside WayneUI, CREED, PROCTOR, PREFLIGHT, SESAME, HELMET, Pinstripe and Sourdough.

> The one way into the Citadel. It only comes down for people who signed in.

Status: scaffolding. The 0.1 build is under way.
